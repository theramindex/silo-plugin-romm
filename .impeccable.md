## Design Context

### Users
Silo users browsing their own RomM library with a desktop keyboard, touch,
TV remote, or gamepad. They want to find a platform or game, see what can be
played in Silo, and resume their own saved progress.

### Brand Personality
Calm, familiar, and content-led. Keep the Silo themes and bundled typography.

### Aesthetic Direction
The user explicitly chose RomM's library interface as the quality reference.
Replace the flat form-and-grid layout with platform navigation, useful browsing
controls, intentional artwork fallbacks, and a proper game-detail page.

### Design Principles
- Organize a large library by platform before presenting thousands of games.
- Let genuine game artwork and platform identities carry the visual character.
- Clean file-derived titles for display; preserve the original file information.
- Make supported browser play easy to find without labeling every other card.
- Preserve profile isolation, controller access, responsive layouts, and themes.

### Compact library refinement
Keep the measured sticky header and its scoped search persistent. Favor a compact
toolbar and removable filters. Personal platform shortcuts are connection-scoped;
Continue playing retains actual played ROM IDs. Never probe playback to decide
Resume. Missing artwork carries illustration only, with one readable title below.
Mobile title, version and play controls form one compact, logical reading sequence.

### Personal home refinement
Use the pinned Games title and horizontal shelves on Home. Keep Collections and
Favorites discoverable even when empty. One rail search owns platform filtering.
Use concise empty states. Play badges must reflect Silo's supported cores, not
the broader set supported by RomM's own players.
